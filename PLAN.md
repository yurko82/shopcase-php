# 📋 ShopCase — План розробки та впровадження інтернет-магазину чохлів

## 🎯 Мета проекту
Створення сучасного, швидкого та конверсійного інтернет-магазину кастомних чохлів для смартфонів із повною інтеграцією з API постачальника **EndorPhone** та доставкою **Новою Поштою**.

---

## 🏗️ Нова Архітектура (Впроваджено 2026-08-26)

### 1. Стек технологій
- **Backend:** PHP 8.1+ (OOP, типізація, модульна архітектура).
- **Сховище даних:** Високопродуктивний швидкий Flat-JSON Engine (`data/`, `data/cache/`, `data/logs/`) з in-memory індексацією.
- **Frontend:** Ванільний SSR + інтерактивні модальні модулі (Vanilla ES6+ JS, CSS Grid/Flexbox, Custom Properties).
- **Зовнішні API:** EndorPhone API v1.0 (залишки матеріалів, автостворення замовлень, трекінг), Нова Пошта.
- **Веб-сервер:** Apache 2.4 / Nginx Proxy, Gzip/Deflate, Browser Caching, `.htaccess` Security Protection.

### 2. Структура проекту
```
j:/site/SC/
├── .env                       # Змінні середовища (API ключі, токени)
├── .env.example               # Зразок конфігурації
├── .htaccess                  # Захист даних (403), Gzip, кешування
├── index.php                  # Головна вітрина (SSR)
├── api.php                    # REST API (замовлення, міста, залишки, трекінг)
├── cron.php                   # Фонова синхронізація залишків API
│
├── app/                       # Серверні класи (OOP)
│   ├── Config.php             # Завантаження .env та констант
│   ├── Database.php           # In-Memory & File Storage Layer
│   ├── EndorPhone.php         # Клієнт EndorPhone API (cURL, транслітерація)
│   ├── CatalogService.php     # Каталог принтів та категорій
│   ├── StockService.php       # Залишки матеріалів для 995 моделей
│   ├── NovaPoshta.php         # Довідник населених пунктів
│   └── OrderService.php       # Створення та валідація замовлень
│
├── views/                     # Шаблони
│   ├── layout/ (header.php, footer.php)
│   ├── components/ (hero.php, categories.php, how-it-works.php, advantages.php)
│   └── modals/ (customizer, order-form, tracking)
│
├── js/                        # Клієнтські скрипти
│   ├── app.js                 # UI, toast-сповіщення, скрол
│   ├── customizer.js          # Візуальний конструктор (вибір моделі + матеріалу)
│   ├── order.js               # Оформлення замовлення
│   └── tracking.js            # Відстеження статусу замовлення
│
├── css/                       # Стилі
│   └── customizer.css, catalog.css, hero.css, main.css, modal.css, form.css...
│
├── design/                    # 22 папки з 238 реальними макетами принтів
└── data/                      # Захищені службові файли (403)
    ├── cache/ (stock.json, designs_catalog.json)
    └── logs/ (orders.log)
```
