# 📖 Документація EndorPhone Drop API v1.0

> Збережено та структуровано на основі офіційної специфікації API (`api.png`).
> Базовий URL: `https://api.endorphone.com.ua/1.0`
> Формат даних: JSON (всі запити та відповіді)
> Метод передачі: HTTP POST (cURL) з параметрами у тілі JSON.

---

## ⚠️ Важливі правила та обмеження
1. **Обмеження на мову запитів (Помилка #1001):**
   - У текстових полях запитів дозволені **лише символи латиниці**.
   - Будь-які українські чи кириличні ПІБ, адреси та коментарі **обов'язково повинні транслітеруватися** перед відправкою.
2. **Формат доставки Новою Поштою:**
   - `city`: Код міста (City Ref UUID) з бази Нової Пошти (наприклад, `e2213642-391c-11dd-90d9-001a92567626`).
   - `warehouse`: Код відділення (Warehouse Ref UUID) з бази Нової Пошти (наприклад, `2bbbceed-e1c2-11e3-8c4a-0050568002cf`).
3. **Структура відповіді:**
   - Успішна відповідь: `{"success": true, "response": ...}`
   - Помилка: `{"success": false, "error": "...", "code": 1001}`

## 📋 Опис методів API

### 1. Створення нового замовлення
- **URL:** `POST https://api.endorphone.com.ua/1.0/orders`
- **Параметри:**
  - `apikey` (string) — Ваш API ключ.
  - `calledMethod` (string) — `"post"`.
  - `properties` (object):
    - `surname` (string, трансліт) — Прізвище отримувача.
    - `name` (string, трансліт) — Ім'я отримувача.
    - `phone` (string) — Телефон у форматі `+380XXXXXXXXX`.
    - `email` (string) — Email отримувача.
    - `city` (string) — Код (Ref) міста з бази Нової Пошти.
    - `warehouse` (string) — Код (Ref) відділення/поштомату з бази Нової Пошти.
    - `payment_type` (string) — Тип оплати: `"1"` — післяплата (накладений), `"2"` — передоплата.
    - `prepayment_type` (string) — Тип передоплати: `"card"` (карта ПриватБанк), `"liqpay"` (LiqPay), `"balance"` (з балансу).
    - `delivery_payer` (string) — Платник доставки: `"1"` — отримувач, `"2"` — магазин.
    - `cash_delivery_payer` (string) — Платник накладеного платежу: `"1"` — отримувач, `"2"` — магазин.
    - `comment` (string, трансліт) — Коментар до замовлення.
    - `products` (array):
      - `code` (string) — Артикул товару (напр. `999m-45`, `{design_id}{mat_code}-{model_id}`).
      - `qty` (string|int) — Кількість.
      - `price` (string|int) — Ціна продажу.
- **Приклад відповіді:**
  ```json
  {
    "success": true,
    "response": {
      "id": 123456
    }
  }
  ```

---

### 2. Перевірка статусу замовлення / замовлень
- **URL:** `POST/GET https://api.endorphone.com.ua/1.0/orders`
- **Параметри:**
  - `apikey` (string)
  - `calledMethod` (string) — `"get"`
  - `ids` (array of string) — Список ID замовлень: `["111111", "123321"]`
- **Приклад відповіді:**
  ```json
  {
    "success": true,
    "response": [
      {
        "id": 123456,
        "state": "В печати",
        "ttn": "",
        "products": [
          { "id": "845m-994", "state": "Готов" },
          { "id": "2833c-150", "state": "В процессе" }
        ]
      }
    ]
  }
  ```

---

### 3. Отримання наявності матеріалів (Весь модельний ряд)
- **URL:** `POST/GET https://api.endorphone.com.ua/1.0/stock`
- **Параметри:**
  - `apikey` (string)
  - `calledMethod` (string) — `"get"`
- **Приклад відповіді:**
  ```json
  {
    "success": true,
    "response": [
      {
        "name": "Apple iPhone X",
        "id": "1060",
        "mat_c": true,
        "mat_m": true,
        "mat_u": true,
        "mat_t": false,
        "mat_b": false,
        "mat_sp": true,
        "mat_pc": true,
        "mat_pm": false
      }
    ]
  }
  ```

#### Розшифровка кодів матеріалів:
| Код в API | Код у коді товару | Назва матеріалу |
|-----------|-------------------|-----------------|
| `mat_u`   | `u`               | Силікон         |
| `mat_b`   | `b`               | TPU чорний      |
| `mat_sp`  | `sp`              | Силікон з посиленими кутами (Antishock) |
| `mat_pc`  | `pc`              | Чохол Bumper    |
| `mat_pm`  | `pm`              | Чохол Bumper MagSafe |
| `mat_c`   | `c`               | 3D пластик глянець |
| `mat_m`   | `m`               | 3D пластик мат  |
| `mat_t`   | `t`               | 2D пластик      |

### 5. Довідник статусів замовлень
- **URL:** `POST/GET https://api.endorphone.com.ua/1.0/getinfo`
- **Параметри:**
  - `apikey` (string)
  - `calledMethod` (string) — `"get"`
  - `option` (string) — `"orderStatus"`
- **Повна таблиця статусів:**
  - `"4"`: Новий (оплачений)
  - `"5"`: Новий (післяплата)
  - `"22"`: Новий (очікує оплати)
  - `"25"`: Новий (очікує обробки)
  - `"6"`: Очікує підтвердження
  - `"26"`: В очікуванні
  - `"18"`: Відмова при дзвінку
  - `"7"`: Підтверджено
  - `"8"`: У друку (В печати)
  - `"29"`: На перевірці
  - `"19"` / `"9"`: Готовий до відправки
  - `"10"`: Відправлено (є ТТН)
  - `"11"`: Прибув, очікує отримання
  - `"21"`: Отримано, гроші в дорозі
  - `"30"`: Отримано, очікує зарахування
  - `"12"`: Отримано
  - `"14"`: Відмова на пошті
  - `"28"`: Відмова після отримання
  - `"13"`: Видалено

### 6. Детальна інформація по замовленнях (з ТТН)
- **URL:** `POST/GET https://api.endorphone.com.ua/1.0/getorderslist`
- **Параметри:**
  - `apikey` (string)
  - `calledMethod` (string) — `"get"`
  - `ids` (array, optional) — Масив ID замовлень: `["111111", "123321"]`
  - `stdate` (string, optional) — Початкова дата у форматі `"ДД.ММ.РРРР"`
  - `endate` (string, optional) — Кінцева дата у форматі `"ДД.ММ.РРРР"`
  - `state` (string, optional) — ID статусу з методу `getinfo`
- **Приклад відповіді:**
  ```json
  {
    "success": true,
    "count": 2,
    "response": [
      {
        "id": "111111",
        "date": "24.03.2019",
        "time": "15:13:15",
        "surname": "Смит",
        "name": "Джон",
        "phone": "+380500000000",
        "delivery": "Нова пошта",
        "city": "Київ",
        "warehouse": "Відділення №1: вул. Пирогівський шлях, 135",
        "state": "12",
        "ttn": "2045000000000",
        "code": ["3993u-45"]
      }
    ]
  }
  ```

### 7. Фінансова інформація: Виплати та Транзакції
- **Виплати:** `GET /1.0/payouts` (`stdate`, `endate`)
  - Відповідь: `[{"date": "01.01.2018", "amount": 22142}]`
- **Транзакції / Виписка:** `GET /1.0/statements` (`stdate`, `endate`)
  - Відповідь: `[{"date": "01.01.2018", "order_id": 123321, "amount": 110, "message": "Зарахування коштів"}, ...]`

## 🚫 Коди помилок API
- `#1001`: Використання кириличних символів (допускається виключно латиниця).
- `#1002`: Не вказано apikey.
- `#1003`: Неприпустимий формат apikey.
- `#1004`: Не вказано calledMethod.
- `#1005`: Неприпустимий формат calledMethod.
- `#1006`: Невірно вказано calledMethod.
- `#1007`: Невірний apikey.
- `#1601` - `#1607`: Помилки параметрів методу `getorderslist` (невірний формат дат, змішування ids та дат).
- `#1701` - `#1703`: Помилки параметрів методу `getinfo`.
